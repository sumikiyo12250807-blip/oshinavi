# OSHINAVI 1日の運転表（2026-08-16 ユーザーと合意）

ユーザーの言葉：「朝開けて、おはようって言うから、そこからスタート。リモートで携帯から進み具合は見られるし、
相談があるときはいつでも相談してもらって、そこで止まっても、私が答えたらそこからまた進ませてくれれば、1日終わる」

**＝完全自動ではない。「止まってよい自走」が正解。** 止まったまま黙らない・答えが来たら即再開する。

## 🚨🚨 いちばん大事な原則＝**止まらない。迷ったのは"その件だけ"よけて進む**（2026-08-26 ユーザー明示）

> 「**迷ったら止まるじゃなくて、迷って、返事が来なかったらおいといて、違うことをして／
> 例えば、畳むかどうかとか、返事が来なかったら、x投稿の準備をしておとか、止まるのはダメよ／
> プッシュも、迷ったのは省いておいてプッシュしとくの／そして、返事がもらえるまで、聞いて、私に**」

1. **質問を出す**（1ターン1問・yes/noか2択・聞きたいことを最初の1行に）
2. **その件だけ保留**＝畳まない／消さない／振り分けない。**現状のまま置く**
3. **すぐ別の作業へ移る**＝X投稿の準備・次のバッチ・ヒール・記事の仕込み。**待ち時間ゼロ**
4. **pushは迷った件を省いて実行**＝便ごと止めない。保留分は次の便へ
5. **返事がもらえるまで、次のターンでまた聞く**。流れた質問を消さない・**自分で決めない**

⚠️「止めて報告」＝**その件を保留にして報告**の意味。作業や便を止める意味ではない。
⚠️「決めて進むほうが速いから」で自分で決めるのは**禁止**（「これは危険」）。
詳細＝[[feedback_selfrun_gates_only_two]] の2026-08-26項。

## 通知の作法（ユーザーは携帯から見ている）

- **PushNotification は節目だけ**＝①ゲートに到達して返事待ちになった時 ②便が終わった時 ③事故が起きた時
- 1行・200字以内・「何を返事すればいいか」を先頭に書く（例：「削除候補24件・URL提示済み。OKなら削除します」）
- 進捗の垂れ流しはしない（[[feedback_new50_silent_selfrun]]）

## 止まった時の作法

- ゲートで止まったら**何を待っているかを1行で明示**して、他にできる自走作業へ移る（ぼーっと待たない）
- ユーザーの返事が来たら**その場から再開**。前置きを長く書かない
- 曖昧な返事（「いいよ」だけ等）は承認と見なさない（[[feedback_user_confirms_expired]] 第5項）

（各便の詳しい手順は下の第1〜4便）

## 📊 空いた時間にやること＝**Xの数字を見に行って分析する**（2026-09-01 ユーザー指示）

> 「**アナリティクスや投稿の結果の数字を見て、文章なんかを分析して、改善していってほしい**」
> 「**明日から、空いた時間に数字を見に行って、分析して**」

**便と便のあいだ・返事待ちの時間はこれに使う。**「やることが無い」は無い。

1. **数字を取る**＝ログイン済みブラウザで `x.com/i/account_analytics` を開き、
   Content の CSV をエクスポート → `tmp/x_content_MMDD.csv` に置く
   （[[project_x_post_analytics]]・画面から読む手順もそこに書いてある）
2. **分析する**＝`python tools/x_analyze.py tmp/x_content_MMDD.csv`
   → `tmp/x_analysis_MMDD.md` に日本語のレポートが出る（コンソールには出さない＝cp932で落ちる）
3. **読む時の決まり（勝手に緩めない）**
   - 🚨**判定は投稿の2日後**。当日の数字で結論を出さない（道具が既定で2日未満を外す）
   - 🚨**母数15本未満の群では勝ち負けを言わない**（道具が「まだ判定しない」と出す）
   - 🚨**跳ねた1本で群が持ち上がる**。レポートは「全体」と「外れ値1本を外した後」を必ず並べて出すので、
     **両方が同じ向きの時だけ**結論にする（2026-08-31に同じ罠を1日で2回踏んでいる）
4. **直す**＝効いた型があれば `X_SCRIPT.md` に**1行だけ**足す／効かなかった行を消す。
   変更には**日付と根拠の数字**を必ず添える。台本以外の場所にルールを増やさない
   （[[feedback_rules_one_place_and_fix_summaries]]）
5. **報告**＝分かったことを日本語で数行。**変わっていないなら「変化なし」と言う**。
   数字が動いていないのに動いたことにしない（[[feedback_no_speculation]]）
