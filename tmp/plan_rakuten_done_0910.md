
# ✅ 9/10 楽天チケットのゲート＝どこまで出来たか（ユーザー指摘4件から）

```
ユーザーの言葉:
 ①「木下グループが売り切れ出てる　売り切れで表示してね」
 ②「楽天から持ってきたチケットが売ってるのしかない件　これから発売のチケット探して、そっちを優先にして」
 ③「ぴあのリンクは0円だけど楽天チケットはアフィリあるから…できるだけ楽天貼って頂戴」
 ④「https://ticket.rakuten.co.jp/features/sada-tour-2026/ これちがうの？」

✅①売り切れの検知＝**生HTMLに1文字も無い**（カードの class は売り切れても active）。
   購入ボタンのAJAX（cms-api の performance/widget・{ids, ecd, eid}）にしか出ない。
   道具＝tools/rakuten_perf_status.py ／ tools/rakuten_mark_soldout.py（朝ルーチン3.45）
   結果＝10枠に「予定枚数終了」

✅②入口＝**post-sitemap の番号は投稿順**。26+27 の1,262本が「今の公演」。
   道具＝tools/rakuten_presale_harvest.py --maps 27,26
   結果＝発売前 3枠 → 15枠

✅③楽天リンク＝いま楽天で買える73ページのうち「登録があるのに貼れていない」18件を洗い出し、
   **13件に貼付（＋25枠）**。5件は楽天に買える枠が無いので貼らない。
   🚨links.rakuten を足す**前に**url が空の枠へ今の飛び先を焼き込む
     （画面は links.rakuten を最優先で使うので、ぴあの枠まで楽天へ飛ぶ）

✅④入口がもう1本＝**static_event-sitemap.xml の特設ページ849本**。丸ごと見ていなかった。
   道具＝tools/rakuten_features_sweep.py
   結果＝そこからしか辿れない公演164本は**全部が過去公演**（実害は小さい）。
        ただし「取り扱いなし＝楽天では売っていない」が行ごとに機械で分かるようになった。
   回収＝さだまさし大阪12/2・12/3 ／ さだ工務店大阪1/16 ／ 割れていたツアーを1つに畳んだ

✅⑤照合が「その締切はその公演のものか」を見るようになった（陰性テストで6件鳴る）
✅⑥ぴあ側にも同じ穴＝tools/pia_mark_soldout_slots.py（枠ごと）で5枠を打ち分けた

数字（9/9 → 9/10）:
   楽天の枠      113 → 140枠
   楽天の発売前     3 →  15枠
   楽天リンク      37 →  50件
   売り切れ表示     0 →  10枠

❌ 残っているもの（2つだけ）
 1. **楽天版の隠れ枠ヒールが無い**（ぴあの heal_stale_deadlines に当たる道具）
    いまは単日形1件・消えているもの0件で**実害ゼロ**。掲載が増えてから作る。
 2. **別レイアウト9件の売り状態**＝これは**楽天が公開していない**と調べ切った（道具の穴ではない）。
    締切は照合できているので「買えない枠を出し続ける」ことにはならない。
```
