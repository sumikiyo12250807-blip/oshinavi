# 11/23 抜き打ち点検（頼み書き）

報告も含めてすべて日本語で。チケット発売日まとめサイト OSHINAVI に載っているカードを、売り場の今のページと1件ずつ突き合わせてください。

- 組2：C:\Users\user\oshinavi\tmp\x1123\spot\sample_2.json（15件）
（あなたの組は頼みの文に書いてある）

## 確かめること（カード1件ずつ）
- 出演者（artist）・公演名・会場・県・公演日（開演時刻）
- tickets の枠ごと：受付名（type）・発売日（startDate）・締切（date）・売り切れの印・飛び先の URL が今も開くか
- 売り場にあるのにカードに無い受付（後から足された先行・一般・当日券）が無いか
- ジャンルがおかしくないか（売り場の札と比べる）
- 売り場のページは tickets の url / links から開く。URL を推測で作らない。WebFetch は「受付終了」を誤読しやすいので、売り切れ・終了の判定は生の文字で確かめる。
- ぴあ・e+ は叩きすぎると 429/503 になる＝1件ごとに数秒あける。

## 判定
- 🔴＝いま買えるのに買えない表示／締切・発売日・公演日・会場の誤り／終わった受付を買えるように出している
- 🟠＝出演者の漏れ・公演名のまま・抜けている受付・県の誤り・ジャンルの誤り
- 🟡＝表記だけの違い
- ✅＝全部一致
