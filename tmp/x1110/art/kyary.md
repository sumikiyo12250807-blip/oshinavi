デビュー15周年のきゃりーぱみゅぱみゅが、来年の春に全国7都市のホールを回るのよ。
ツアーは2023年のワールドツアー以来で、国内のツアーは2022年以来なの。
まずはツアーが決まった日の話をさせて。
発表は8/22、神奈川のぴあアリーナMMで開かれた『PAMYU FES 〜Kyary Pamyu Pamyu 15th Anniversary〜』のステージだったの。
新しい学校のリーダーズ、氣志團、木村カエラ、FRUITS ZIPPER、MONGOL800が集まって、デビュー15周年をお祝いしたのよ。
同じ日に、自分の誕生日の1/29に6枚目のアルバムを出すことも発表されたわ。
チケットぴあは、このツアーを「自身の誕生日にリリースされるアルバムを引っさげて」回るツアーと紹介しているの。
㊟アルバムの詳しいことは後日発表ですって。
ここからがツアーの話。
初日はR9年 3/19(金)の神奈川・厚木市文化会館 大ホールで、OPEN 17:00 / START 18:00よ。
そのあと3/28(日)大阪・NHK大阪ホール、4/18(日)福岡・福岡市民ホール 大ホール、5/9(日)愛知・岡谷鋼機名古屋公会堂 大ホール、5/15(土)北海道・カナモトホール、5/30(日)広島・広島文化学園HBGホールと回るの。
最後は6/12(土)の東京・SGC HALL ARIAKEで、OPEN 16:30 / START 17:30よ。
大阪・福岡・愛知・広島はOPEN 16:00 / START 17:00、北海道はOPEN 16:30 / START 17:30なの。
料金の話もさせて。
公式のお知らせでは、指定席 7,500円(税込)よ。
ここからがチケットの話。
チケットぴあでは、北海道・カナモトホールの4次プレリザーブが11/11(水) 11:00〜11/23(月・祝) 23:59よ。
