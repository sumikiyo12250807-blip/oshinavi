## 1. ゲーム『ドラゴンクエスト』シリーズとは

- 公式の説明：「プレイヤー自身が主人公となり、世界を脅かす魔王を倒すために壮大な冒険物語を紐解いていく」日本を代表するロールプレイングゲーム（RPG）。
  → https://www.dragonquest.jp/about/
- 第1作の発売は1986年5月27日、ファミリーコンピュータ用。
  → https://www.dragonquest.jp/about/
  → http://www.dragonquest.jp/30th/history/1.html （表記は「対応機種：ファミコン／発売日：1986年5月27日」）
- ゲームデザインは堀井雄二（「誰にでも親しみやすいRPG」として創出）、モンスター・キャラクターデザインは鳥山明、音楽はすぎやまこういち。
  → https://www.dragonquest.jp/about/
- 公式の説明：すぎやまこういちは「当時ゲーム音楽としては珍しかったオーケストラ用の楽曲をゲームに採用」した。
  → https://www.dragonquest.jp/about/
- シリーズは100を超えるタイトルを出し、全世界で累計1億本以上の出荷・ダウンロード販売（公式の記載どおり）。
  → https://www.dragonquest.jp/about/
- 2026年5月27日でシリーズ誕生40周年。5月27日は「ドラゴンクエストの日」。
  → https://www.dragonquest.jp/news/detail/4245/
- 主催者も「1986年に第1作目がリリースされてから今年40周年」と書いている。
  → https://kyodonewsprwire.jp/release/202607142533
- シリーズは今も続いている（ナンバリング最新作『ドラゴンクエストXII 選ばれし運命の炎』が制作中と公式が記載＝2021年10月7日の訃報文中）。
  → https://www.dragonquest.jp/news/detail/3546/
  ※XIIの発売日は今回調べていない（演目外のため）。

### 各作品の公式あらすじ・特徴（同じ9ページから、要点だけ）
- I：勇者ロトの血を引く主人公が悪の化身・竜王を倒し、世界に光を取り戻す。コマンド入力システムの採用など、その後の家庭用RPGに大きな影響を与えた。 → http://www.dragonquest.jp/30th/history/1.html
- II：前作から100年後。大神官ハーゴンの野望から世界を守るため、前作の勇者の血をひく3人の子孫が立ち上がる。 → http://www.dragonquest.jp/30th/history/2.html
- III：主人公が16歳の誕生日を迎えた朝から始まる。大魔王バラモス討伐の旅に出たまま帰らなかった父の遺志を継ぐ。人気は発売時期に最高潮に達し「社会現象にまでなった」。転職システムもこの作品で実現。 → http://www.dragonquest.jp/30th/history/3.html
- IV：全5章のオムニバス形式。第5章で主人公が各章の仲間たちとパーティを組む。 → http://www.dragonquest.jp/30th/history/4.html
- V：父親と旅を続ける少年が主人公。親子三代にわたる大河的なドラマ。モンスターを仲間にできるシステムは、のちの「ドラゴンクエストモンスターズ」シリーズへ発展。 → http://www.dragonquest.jp/30th/history/5.html
- VI：最初から2つのワールドマップを行き来するストーリー構成。 → http://www.dragonquest.jp/30th/history/6.html
- VII：世界にたったひとつだけの島に住む少年が主人公。「石版」から冒険が始まる。シリーズ初の3Dマップ、「はなす」システムを採用。 → http://www.dragonquest.jp/30th/history/7.html
- VIII：呪いで時間の止まった国と、呪われた一振りの杖。「トゥーンシェイド」の描画で、アニメーションの世界を歩き回る感覚。 → http://www.dragonquest.jp/30th/history/8.html
- IX：シリーズ本編初の携帯型ゲーム機専用ソフト。主人公は“天使”。シリーズ初のマルチプレイ（最大4人）、すれちがい通信が話題に。 → http://www.dragonquest.jp/30th/history/9.html

## 2. 音楽の歴史

### すぎやまこういち（人物）
- 1931年4月11日、東京都生まれ。作曲家。フジテレビのディレクターを経て作曲家としても活動。「亜麻色の髪の乙女」「学生街の喫茶店」などのヒット曲、CM、アニメ、映画音楽、東京・中山競馬場の発走ファンファーレなども手がけた。
  → https://www.dragonquest.jp/news/detail/3546/
- 「ドラゴンクエスト」シリーズの音楽を発売以来担当。シリーズ500曲以上の楽曲のすべてをひとりで作曲。
  → https://www.dragonquest.jp/news/detail/3546/
- **2021年9月30日に逝去（90歳）**。スクウェア・エニックス公式が2021年10月7日に発表。
  → https://www.dragonquest.jp/news/detail/3546/
  → https://www.jp.square-enix.com/company/ja/news/2021/html/8081b94c804b1ae3c6fe5fb0083625c0d1132b0b.html
  → https://sugimania.com/welcome.html （すぎやまこういち公式サイト「すぎやまこういち逝去に関するお知らせ」：2021年9月30日、90歳で永眠）
  ※記事では「現役」と書かない。公式サイト自身も「故・すぎやまこういち」と表記。 → https://sugimania.com/
- 最後の仕事は制作中の『ドラゴンクエストXII 選ばれし運命の炎』の作曲。
  → https://www.dragonquest.jp/news/detail/3546/
- 受賞など（公式の経歴欄）：1988年『交響組曲 ドラゴンクエストIII』で第30回日本レコード大賞特別企画賞／2016年「世界最高齢でゲーム音楽を作曲した作曲家」としてギネス記録認定／2018年旭日小綬章／2020年文化功労者／2021年東京2020オリンピック開会式で『ロトのテーマ』が使用された。
  → https://www.dragonquest.jp/news/detail/3546/
- ドラゴンクエスト「序曲」が2017年JASRAC賞銅賞、2020年度JASRAC賞銀賞。
  → https://sugimania.com/welcome.html

### オーケストラで演奏する「交響組曲」とコンサートの始まり
- 公式の経歴文：「青少年のオーケストラ入門になればと、オーケストラによる交響組曲『ドラゴンクエスト』のコンサートを各地で実施」。
  → https://www.dragonquest.jp/news/detail/3546/
- 交響組曲「ドラゴンクエスト」＝ゲームの曲を作曲者自身がオーケストラ用の組曲にしたもの。I〜IXそれぞれに交響組曲があり、すぎやまこういち指揮・東京都交響楽団などの録音がCDで出ている（例：交響組曲「ドラゴンクエストIX」星空の守り人＝2010年2月10日発売）。
  → http://sugimania.com/CD/cd-1.html
  ※「交響組曲とは」を一文で定義した公式の文は見つからなかった。上の説明はCD一覧（公式）の中身から言える範囲。
- いちばん古い録音：組曲「ドラゴンクエストI」＋組曲「ドラゴンクエストII」悪霊の神々＝1986年8月・11月・12月録音（アポロン盤音源）、東京弦楽合奏団（N響のメンバーによる）、指揮すぎやまこういち。公式サイトの紹介文は「ドラクエ・サウンドの原点はこれだ！！」。
  → https://sugimania.com/sugilabel/category01.html
- 交響組曲「ドラゴンクエストIII」そして伝説へ…＝1987年12月録音、NHK交響楽団、指揮すぎやまこういち。
  → https://sugimania.com/sugilabel/category01.html
- **ファミリークラシックコンサート（すぎやまこういちが始めたドラクエのコンサート）**：第1回は1987年8月20日、サントリーホール。以後ほぼ毎年夏に開催、2020〜2023年は開催なし（第33回2019年8月7日の次が第34回2024年7月29日）。今年は第36回＝2026年9月22日（火・祝）東京芸術劇場（東京都交響楽団・指揮 大井剛史・交響組曲「ドラゴンクエストVII」）。
  → http://sugimania.com/family/index.html
  → https://sugimania.com/ （第36回の出演・演目・「チケットは完売しました」の記載）
- 2016年の第30回ファミリークラシックコンサートは東京芸術劇場コンサートホールで9月3日。
  → https://sugimania.com/welcome.html
