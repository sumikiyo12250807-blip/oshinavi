## 2. 🔒機械ゲートの案（この条件を満たさないものは投入しない）

`tools/gate_tiget_slots.py` は**集合（set）で突合している**ので、**同じ枠が2本ある・枠が畳まれて減っている**のを
原理的に見逃す。まずそこを直すのが効く。

### 優先1（嘘・取りこぼしに直結）
```python
# G1: 枠の数が生データと一致する（setでなくリストで数える）
assert len(entry.tickets) == sum(len(p.tickets) for p in raw.programs if p.date >= today)
#     一致しないなら「なぜ減ったか」を1枠ずつ理由付きで出す。理由が
#     「同じ見た目だから畳んだ」なら NG（畳む前に見分けを付ける＝G2/G3へ）

# G2: 同じ日に公演が2つ以上あるなら、バッジに開場時刻が入っている
if len({p.datetime_text for p in raw.programs if p.date == d}) > 1:
    assert re.search(r'（.*\d{1,2}/\d{1,2} \d{1,2}:\d{2}公演）', ticket.type)

# G3: 1つのカードの中に、画面に出る形（バッジ文字＋出る日付＋印）が同じ枠が2つ以上あってはいけない
key = (badge_text(t), t.startDate if t.saleEndUnknown else t.date, t.soldout, t.saleEnded)
assert len({key for t in tickets}) == len(tickets)

# G4: 締切は公演日を超えない（配信券だけ例外）
assert t.date <= entry.date or ('配信' in entry.name or '配信' in t.type)

# G5: 落とした枠・落としたイベントの理由を必ず数えて出す。
#     (a)「受付前で受付期間が無い」かつ「validFromが1つ」かつ「validFrom >= today」＝救えるのに捨てている → NG
#        （今日は 63イベント＋3枠）
#     (b) validFrom が過去（ページが矛盾）＝日付を作らない。ただし
#        「その結果カードの枠が売切れ・販売終了だけになる」なら投入せず報告（今日は id12744・12561 の2件）
```

### 優先2（券種名の質）
```python
# G6: 券種名が空のまま「チケット」に倒れた枠の割合
#     名前も値段も取れない枠が1つでもあるイベントは投入しない（＝ハーベスタの読み落ち。今日は460枠/87イベント）
assert not (ticket.raw_name == '' and ticket.raw_price is None)

# G7: 1つのカードの中で同じ券種名が2つ以上になるなら、値段か公演時刻で必ず見分けが付いている
# G8: 券種名に SELLER_SIDE（出店・ブース・委託・即売・参加エントリー・駐車・案内登録・協賛のみ）が
#     入っている枠は入れない（※イベント名だけでなく券種名にも当てる。
#     「取り置き」「協賛込み」「チェキ撮影会」は巻き添えにしない＝除外語の否定形を持つ）
```

### 優先3（畳み・雛形）

# G9: ツアー畳みは「尻尾が都道府県名・市名・会場名」のときだけ許す。
