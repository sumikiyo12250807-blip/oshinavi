# 「載っているが、その週に発売が始まる枠が無い」層（2026-09-10 発見）

## 何が起きているか

ローチケの週スキャンに出てくるのに、OSHINAVI の「今週発売」の窓に出てこない組がいる。
調べたら **エントリは載っている。でも枠が「先行」だけで、一般発売の枠が無い**。

## なぜどの道具も気づかなかったか

- `check_zero_badge.js` … **枠が1つでも生きていれば通る**（先行が生きているので出ない）
- `check_big_artists.py` … **名前があれば「載っている」で終わる**（枠の中身を見ない）
- `reconcile_pia --new` … 新着プールしか見ない
- ヒール … `startDate == today` 型が対象

## 道具にした（2026-09-10）

```
python tools/check_big_artists.py <json> --window 2026-09-14:2026-09-20
```
`--window` で「その窓に startDate を持つ枠があるか」まで見る。
2週ぶんで **8件＋8件** が出た。
